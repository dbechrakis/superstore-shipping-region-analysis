# Superstore Shipping & Region Analysis

Data Visualization course project (M.Sc. Data Science). Analyzes the classic Superstore sales dataset with a focus on shipping performance and regional sales patterns, combining a Python notebook with a Power BI dashboard.

## Contents

- Python notebook analyzing shipping times, delivery modes, and regional sales/profit trends, exported as a standalone HTML report.
- Power BI dashboard (`.pbix`) built on the same dataset for interactive exploration.
- Written report summarizing findings.

## Status

The notebook, HTML report, and Power BI file are being added directly on GitHub as a follow-up upload (binary/Jupyter formats render better via direct upload).
